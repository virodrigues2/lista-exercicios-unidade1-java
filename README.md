# 💻 Lista de Exercícios - Unidade 1 (Java POO)

Este repositório contém 10 exercícios desenvolvidos em **Java**, com foco em **Programação Orientada a Objetos (POO)**.  
Cada classe representa um exemplo prático de uso de atributos, métodos e encapsulamento.

## 📂 Estrutura dos arquivos

| Nº | Classe | Descrição |
|----|---------|------------|
| 1 | Circulo.java | Calcula área e perímetro de um círculo |
| 2 | Pessoa.java | Representa uma pessoa com nome e idade |
| 3 | Livro.java | Exibe informações de um livro |
| 4 | Retangulo.java | Calcula área e perímetro de um retângulo |
| 5 | Animal.java | Representa um animal e seu som |
| 6 | Produto.java | Aplica desconto sobre o preço |
| 7 | Triangulo.java | Calcula área de um triângulo |
| 8 | ContaBancaria.java | Permite sacar e depositar valores |
| 9 | Carro.java | Simula ações básicas de um carro |
| 10 | Funcionario.java | Calcula aumento salarial |
